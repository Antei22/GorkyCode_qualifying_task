# Граница голосового слоя

Текущая реализация STT/TTS находится в `frontend/src/voice/browser.ts`:
браузерное распознавание русской речи и SpeechSynthesis. Аудио backend не принимает.
Расшифровка редактируется пользователем и отправляется в обычный `/api/chat`.

При добавлении серверного STT создать здесь адаптер провайдера и отдельный
HTTP endpoint с ограничениями длительности/размера/формата аудио. Не помещать
обработку аудио в доменные модели или репозиторий. Бизнес-логика получает текст
независимо от источника. Текущий браузерный STT доступен не во всех браузерах и
может зависеть от внешнего сервиса браузера; автономная работа не обещается.
